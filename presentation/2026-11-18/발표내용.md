# 자동차 조립 공정 디지털 트윈 발표자료

기준일: 2026-11-18 / Unreal Engine 5.8 / 발표 설명 약 5~7분 + 선택한 기능 시연

## 발표의 핵심

**가상 조립 공정에서 설비 배치, 부품 상태, 센서 조건을 바꾸고 작업 가능 여부와 이상 대응을 비교하는 디지털 트윈을 개발하고 있다.**

PID와 IK는 로봇을 움직이는 수단이다. 최종 목표는 현업에서 설비 배치, 작업 분담, 불량 원인과 대응 절차를 검토하는 데 도움이 되는 도구다. 현재는 실제 설비와 연결하기 전의 시뮬레이션 기반 시제품이다.

## 1. 진행되고 있는 내용

### 현재 구현

- 차체 반입 → 휠 4개 장착 → 구역 이송 → 문 4개 장착을 하나의 공정으로 연결했다.
- 부품 접근, 파지, 운반, 정렬, 체결, 해제와 후퇴를 단계별로 수행한다. 현재 문은 간섭을 줄이기 위해 양쪽 뒷문을 먼저 장착하고 앞문을 장착한다.
- 로봇의 목표 자세를 IK로 계산하고 PID 계열 제어로 추종한다. 차체, 바닥, 등록된 구조물과 로봇 링크의 간섭을 검사한다.
- 최종 삽입 전 각도를 맞추고 위치를 정렬한 뒤, 정해진 자세를 유지하는 직선 삽입을 사용한다.
- 네 휠에 공통 파지 접촉·마찰·낙하 모델을 적용했다. 문의 물리 상태는 처음 파지한 시점부터 부품별로 유지한다.
- 가상 센서, 측정 유효성, 사건 기록, 부위별 손상 결과를 UI에 연결했다.
- 같은 로봇 구현을 좌우·앞뒤 작업에 재사용하도록 설비, 부품 물성, 작업 연결과 실행 상태를 분리했다.
- `다음 공정`으로 이전 작업을 건너뛰고 문 작업 위치에서 바로 시연할 수 있다.

### 활용하려는 질문

- 로봇의 배치와 작업 분담을 바꾸면 작업 가능한 범위와 공정 시간이 어떻게 달라지는가?
- 부품 위치나 마찰, 질량, 센서 상태가 바뀌면 어느 단계에서 작업이 멈추는가?
- 재측정·재공급으로 복구할 수 있는 상황과 작업자 개입이 필요한 상황은 무엇인가?
- 잘못 안착한 부품을 체결했을 때 어떤 부위의 하중이 커지는가?

이 결과는 가상 조건의 비교 자료다. 실제 생산성이나 불량률을 수치로 예측하려면 현장 데이터 보정이 추가로 필요하다.

## 2. 시뮬레이터에서 재현할 수 있는 돌발상황

| 상황 | 변화하는 입력 또는 상태 | 관찰할 대응 |
|---|---|---|
| 부품 누락 | 공급 위치에 부품이 없음 | 공급 대기, 대체품 공급 후 재검사 |
| 부품 위치 변화 | 픽업 또는 차체 위치가 달라짐 | 센서 재측정, 목표와 경로 재계산 |
| 센서 끊김·레이저 재스캔 | 측정이 무효하거나 갱신되지 않음 | 대기·중단 또는 새 측정 확인 후 재시도 |
| 저마찰·운반 중 마찰 저하 | 접촉면이 전달할 수 있는 접선 힘 감소 | 미끄러짐, 접촉 상실, 낙하 및 설정된 회수 절차 |
| 과중량 | 부품 질량과 요구 하중 증가 | 파지 한계 초과, 낙하·교체 시연 |
| 휠·문 규격 불량 | 부품의 규격을 허용 범위 밖으로 변경 | 규격 검사, 격리, 대체품 재검사 |
| 도킹 초과 | 차체가 정지점을 지나감 | 초과 위치 측정, 후진 재도킹 |
| 지그 이물질 | 받침 한 곳의 유효 접촉면 높이 변경 | 안착 불량 감지, 정상 체결 차단 |
| 잘못된 안착 상태에서 강제 체결 | 안착이 불량한데 체결력을 적용 | 접촉력 증가, 손상 부품·부위 기록 후 중단 |
| 작업 경로의 구조물 간섭 | 등록된 충돌 형상과 경로가 겹침 | 유효한 우회 경로 탐색 또는 실행 차단 |

`상황 시연`에서 개별 사례를 선택한다. `무작위 상황`은 기본 정상 35%, 돌발상황 65%이며 돌발 후보 사이에는 같은 확률을 사용한다. 이 확률은 시연 설정값이고 실제 공장 사고 통계가 아니다. 선택 시드를 보관하며, 문 공정으로 건너뛰면 문에 해당하는 후보에서 다시 선택한다.

작업자 회수·대체품 공급은 절차 시연이다. 사람의 신체 접촉, 상해나 안전거리의 인증된 해석까지 구현한 것은 아니다.

## 3. 사용한 알고리즘과 물리

### IK: 목표 위치·방향을 관절 각도로 변환

로봇 끝단의 작업 기준점인 TCP가 부품을 잡거나 장착할 목표 자세를 받아 6개 관절의 목표 각도를 계산한다. 현재는 감쇠 최소제곱 방식의 수치 IK를 사용한다. 관절 한계와 도달 가능성을 함께 확인하며 계산 실패를 성공으로 처리하지 않는다.

### 경로 계획: 이동 가능한 경로 선택

직접 이동 경로의 충돌을 먼저 검사한다. 필요하면 관절 공간의 양방향 샘플링 탐색과 경로 단축을 사용한다. 차체·바닥·등록된 구조물을 고려하고 이동 중에도 다시 검사한다. 제한된 계산 예산 안에서 찾는 경로이므로 전역 최단·최적 경로를 보장하지 않는다.

### PID 계열 제어: 목표와 현재 자세의 오차를 줄임

P는 현재 오차, I는 누적 오차, D는 목표 속도와 현재 속도의 차이를 반영한다. 목표 궤적의 속도 정보를 함께 사용하고 적분 누적과 출력에 제한을 둔다. 일반 속도 서보와, 접촉 하중·관성·구동 토크 한계를 반영하는 간소화 토크 모드를 구분한다.

### 공정 상태기계와 가상 센서

공정은 공급 확인, 파지, 운반, 정렬, 체결, 해제 단계로 나뉜다. 센서 어댑터가 가상 상태를 측정하고 제어기는 값·유효성·측정 시각을 확인해 다음 단계로 진행한다. 현재 가상 센서를 사용하며 실제 카메라 영상 인식이나 실물 센서 스트리밍은 구현 범위 밖이다.

### 접촉·마찰·관성

- 부품별 질량, 관성, 자세, 선속도·각속도를 유지한다.
- 접촉점에 등가 스프링·감쇠와 마찰 제한을 적용하고 중력과 모멘트를 적분한다.
- 마찰 한계는 대략 `마찰계수 × 접촉면을 누르는 힘`에 비례한다. 운반 중 가속도와 자세, 실제 접촉점에 따라 유지 가능한 하중이 달라진다.
- 휠을 일정 미끄러짐 거리에서 강제로 떼는 대신, 유한한 접촉면을 벗어나 지지력을 잃으면 낙하하도록 한다.
- 로봇에는 링크 질량·무게중심과 부품 반력을 관절 하중에 반영하는 근사 모델을 사용한다.
- 제어 기준 간격은 1/120초, 접촉 적분의 기본 내부 간격은 최대 0.5ms다. 렌더링 FPS와는 별개다.

### 지그·체결·손상

지그는 받침, 위치 결정 요소와 클램프로 문을 지지한다. 이물질은 한 받침의 접촉면 높이로 표현하며, 현재 별도의 이물질 메시가 나타나는 방식은 아니다. 안착 상태를 확인하고 체결한다. 힘이 부위별 설정 한계를 넘으면 부품/차체/지그 ID, 손상 위치, 최대 힘과 한계를 기록한다. 메시 찌그러짐이나 실제 판재의 유한요소해석(FEM)은 구현하지 않았다.
