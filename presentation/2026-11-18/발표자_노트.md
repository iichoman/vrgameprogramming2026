## 2. 데모 진행표

발표 전 `factory_p1`을 열고 최신 코드를 반영한 새 Play에서 확인한다. PDF와 게임 창을 번갈아 보여주며, 재현성이 필요한 본 시연은 고정된 상황을 선택한다.

| 순서 | 실제 조작 | 확인할 결과 | 설명 포인트 |
|---|---|---|---|
| 1. 정상 문 조립 | `상황 시연` → `정상` → 상단 `다음 공정` | 문 구역으로 즉시 배치, 뒷문부터 조립 | 건너뛴 휠은 미검사, 문 제어·검사는 실제 실행 |
| 2. 이물질 | `편집 복귀` → `상황 시연` → `지그 이물질` → `다음 공정` | 안착 불량에 의해 체결 차단 | 목표 위치에 갔다는 것만으로 체결 승인하지 않음 |
| 3. 손상 | `편집 복귀` → `강제 체결 손상` → `다음 공정` | 중단 후 결과 탭의 손상 부위·힘 표시 | 잘못된 안착을 억지로 체결한 결과 |
| 4. 선택 시연 | `편집 복귀` → `운반 중 마찰 저하` → 대상 휠 선택 → `실행` | 미끄러짐·낙하·설정된 복구 절차 | 이 사례는 휠 공정이므로 `다음 공정`으로 건너뛰지 않음 |
| 5. 선택 시연 | `편집 복귀` → `무작위 상황` → `실행` 또는 `다음 공정` | 선택된 상황과 시드 표시 | 정상도 나올 수 있으며 실제 사고 확률을 추정한 값은 아님 |

- 시간이 짧으면 정상 문 접근·파지까지만 보여주고 초기화한 뒤 이물질 차단 또는 손상 사례 하나를 보여준다.
- 정상 조립과 고장 조건의 비교에는 같은 배치·같은 부품 설정을 유지한다.
- `다음 공정`은 즉시 초기 조건을 준비하는 시연 기능이다. 이동 구간을 실제 컨베이어 물리로 해석한 결과는 아니다.
- 진행 중인 미완료 휠 작업을 스킵하면 해당 작업과 파지/낙하/복구 상태를 정리하고 공급 위치로 돌린다. 이미 완료한 휠은 유지한다.
- 현재 마지막 작업인 문 공정에서는 다음 등록 공정이 없으므로 스킵 버튼이 비활성화된다.
- 화면이 복잡하면 센서 탭에서 `센서·접촉 위치 표시 (측정은 계속)`를 끈다. 손상 결과 표시는 별도다.
- 이물질 덩어리 메시가 보이지 않는 것이 현재 구현 방식이다. 안착 결과와 손상 부위를 설명한다.

## 3. 기술 설명: IK와 제어

### TCP와 좌표

TCP(Tool Center Point)는 부품을 잡거나 작업할 때 기준으로 삼는 공구 끝단의 위치와 방향이다. 로봇 베이스, 마지막 관절, 공구, 부품, 차체의 로컬 좌표를 명시적으로 변환한다. TCP 보정이 틀리면 관절은 목표에 도달했는데 부품의 실제 접촉점은 어긋날 수 있다. 현재 파지 TCP와 기준 설정을 사용하고 있으며 실물 공구를 측정한 정밀 보정은 후속 작업이다.

### 수치 IK

순기구학 FK는 관절 각도 q로 TCP 자세를 계산한다. IK는 목표 TCP 자세와 FK 결과의 차이를 줄이는 q를 반복해서 찾는다. 현재 자코비안과 감쇠 최소제곱을 사용한다.

개념식: `Δq = Jᵀ (J Jᵀ + λ² I)⁻¹ e`

`e`는 위치·방향 오차, `J`는 관절 변화에 따른 TCP 변화, `λ`는 수치적 불안정을 줄이는 감쇠다. 관절 각도 제한, 초기 추정값과 반복 종료 조건을 사용한다. 이 식을 신경망 학습 기반 IK라고 소개하지 않는다.

### PID 계열 추종

오차 `e = 목표 각도 - 현재 각도`로 정의한다. 일반 설명은 `u = Kp e + Ki ∫e dt + Kd de/dt`다. 실제 속도 서보 구현에는 목표 궤적 속도 feedforward가 더해지고, D항은 목표 속도와 현재 속도의 차이를 이용한다. 적분 한계와 조건부 적분으로 출력 포화 시 누적 오차를 제한한다.

속도 서보는 1차 모터 응답, 속도·가속도와 관절 각도 제한을 적용한다. 토크 모드는 관성에 따른 P/I/D 계열 이득, 외부 하중 보상과 구동 토크 포화를 사용해 관절 속도·각도를 적분한다. 토크 모드의 이득이 UI의 일반 Kp/Ki/Kd와 같은 경로로 사용되는 것은 아니다. 모든 상용 로봇의 서보 특성을 그대로 재현한 것으로 설명하지 않는다.

### 충돌 고려 경로

직접 관절 이동을 먼저 검사하고 막히면 양방향 샘플링 탐색으로 연결 가능한 관절 경로를 찾는다. 연결 구간을 촘촘하게 검사하고 불필요한 우회점을 줄인다. 실제 추종 중에도 충돌과 삽입 경로 허용 범위를 검사한다. 경로 계산은 제한된 탐색·시간 예산을 사용하므로 전역 최적 경로와 모든 동적 장애물 회피를 보장하지 않는다.

## 4. 기술 설명: 물리

### 부품 상태와 시간

문 부품은 최초 파지부터 ID, 질량, 관성, 자세, 속도, 접촉 연결과 손상 이력을 유지한다. 다음 문 작업이 시작되어도 이전 문의 상태를 보존한다. 공정 정지는 구동 명령을 멈추며 부품 중력을 끄는 기능이 아니다. 새 실험의 Reset과 시연용 스킵은 명시적인 초기 조건 변경이다. 공급 랙의 모든 재고가 처음부터 독립적인 자유 접촉 물리를 사용하는 것은 아니다.

제어 기준은 120Hz이며 접촉 계산은 기본 최대 0.0005초 간격으로 나눈다. 120Hz는 시뮬레이션 갱신 주기이지 화면 FPS나 실시간 처리 성능의 보장이 아니다.

### 접촉 모델

접촉면을 유한한 크기의 패드로 근사한다. 접촉점의 간극·상대 속도로 스프링과 감쇠 반력을 계산하고, 접선 힘을 마찰 용량으로 제한한다. 기본 개념식은 다음과 같다.

- 병진 운동: `m a = ΣF`
- 회전 운동: `I α + ω × (I ω) = Στ`
- 접촉 반력: `F ≈ k δ + c δ̇`에 단방향 접촉·예압·구동력 제한 적용
- 마찰 한계: `|F접선| ≤ μ N`

접촉점이 패드 가장자리를 벗어나면 그 지지력이 사라진다. 휠의 일정 미끄러짐 경보값으로 강제 분리하던 방식 대신 실제 접촉 상실을 이용한다. 다만 여기서 실제 접촉은 계산용 프록시 접촉이며 모든 메시 삼각형의 물리 접촉이나 고무 변형의 정밀 해석은 아니다.

### 기본 휠 설정 예

| 항목 | 기본 설정 | 의미 |
|---|---:|---|
| 질량 | 18kg | 부품 레시피의 가정값 |
| 외반경 / 내반경 | 0.33m / 0.18m | 환형 물체의 관성 근사 |
| 폭 | 0.20m | 관성·충돌 크기 계산 |
| 마찰계수 | 0.65 | 기본 접촉면 설정 |
| 집게 총 구동력 상한 | 1200N | 네 접촉점에 분산되는 힘 한계 |
| 집게 닫힘 시간 | 0.08초 | 구동력 상승 시간 |
| 최대 내부 적분 간격 | 0.5ms | 접촉 계산의 기본 세분화 간격 |

예를 들어 18kg의 정적 무게는 약 177N이다. 이상적인 전체 접촉에서 `0.65 × 1200 = 780N`은 단순 마찰 용량의 설명 예시다. 실제 모델에서는 접촉 수·방향·운반 가속도·회전과 패드 이탈에 따라 달라지므로 이 숫자를 안전한 허용 적재량으로 제시하지 않는다. 위 수치는 실차·제조사 실측값이 아니다.

### 지그와 손상

받침, 로케이터와 클램프가 위치 결정과 하중 지지를 담당한다. 현재 기본 지그는 설정된 접촉점 레시피를 사용한다. 명시적인 `PhysicalFixture`를 연결하면 해당 지그 접촉 설정을 사용한다. 과거 CamryAssemblyPreview에서 보이는 지그 메시가 자동으로 이 물리 레시피에 연결된다는 뜻은 아니다.

이물질은 한 받침의 유효 접촉면 높이를 바꾼다. 힘과 변위의 이상적인 관측으로 간섭 두께를 추정한다. 기본 예에서 4mm 이물질은 정상 체결을 차단한다. 20mm 이물질 조건에서 강제 체결한 기존 실행은 하부 앞 받침의 약 1498N을 기록했고, 설정된 1000N 한계를 넘어 손상으로 분류했다. 다른 설정·배치에서는 결과가 달라질 수 있다.

손상 기록에는 부품/상대편 ID, 부위, 위치, 최대 힘, 설정 한계와 등가 탄성 변위가 남는다. 메시 변형, 소성 변형, 균열, 파단 후 연결 해제, 누적 피로 또는 실차 판재의 FEM은 포함하지 않는다. `탄성 변위`는 등가 스프링 모델의 변위이며 판재 전체의 형상 변형 결과가 아니다.

### 로봇 부하

링크 질량과 무게중심, 관절 관성, 구동 한계 및 공구의 접촉 반력을 관절 축에 투영한다. 현재 대각 관성 근사와 이상적인 하중 보상을 사용한다. 전체 다물체 관성 행렬, 관절 간 동역학 결합, 제조사 실측 서보·감속기 특성의 완전한 재현은 아니다. 관절 범위·속도는 상용 로봇 참조 설정을 사용하지만 받은 메시와 실물 모델의 정확한 일치를 입증한 것은 아니다.

## 5. 센서 적용 범위

- 센서 입력: 부품 존재·위치, 파지 접촉과 힘, 차체 도착·속도, 정렬 오차, 안착 상태 등.
- 센서 계약: 측정값, 단위, 부품/작업 ID, 유효성, 측정 시각과 최대 유효 나이.
- 센서 표시를 꺼도 측정과 물리 계산은 계속된다.
- 네 휠의 파지 접촉 모델과 파지 센서 표본은 공통화되어 있다.
- 기존 휠 규격/허브 3단계 레이저 시연은 왼쪽 앞휠 전용이다. 모든 검사가 네 휠에 똑같이 일반화됐다고 말하지 않는다.
- 카메라 영상 인식, 실제 센서 스트리밍, 현실적인 모든 잡음·반사·가림 모델은 미구현 또는 후속 범위다.

## 6. 예상 질문과 답변

**실제 공장의 조립 공정과 같은가요?**  
특정 Toyota 라인의 작업 순서나 인력 구성을 그대로 복제하지 않았다. 위치 결정, 지지, 정렬, 체결과 검사라는 공정 원리를 가상 자동화 셀에 적용했다. 실제 적용에는 대상 공정 자료와 설비 보정이 필요하다.

**왜 디지털 트윈인가요? 실제 장비와 연결되어 있나요?**  
현업용 디지털 트윈을 목표로 물리·센서·제어·제품 상태를 분리한 시뮬레이션 기반 시제품이다. 현재 실물 설비와의 실시간 동기화까지 구현한 상태는 아니다.

**AI가 로봇의 다음 행동을 결정하나요?**  
AI를 설계, 코드 작성, 디버깅과 검증 보조에 활용했다. 실행 중 핵심은 IK, 경로 탐색, PID 계열 제어, 상태기계와 물리 계산이다. 학습된 신경망이나 강화학습이 제어한다고 설명하지 않는다.

**물체가 떨어지는 것은 미리 정한 애니메이션인가요?**  
파지 입력을 바꿔 접촉·마찰 용량이 달라지고, 계산에서 접촉을 잃으면 낙하한다. 이후 작업자 회수·격리·대체품 공급은 설정된 절차 시연이며 사람 자체의 생체역학을 계산하지 않는다.

**이물질이 화면에 안 보이는데 무엇을 구현했나요?**  
접촉 계산에서 받침 한 곳의 유효 높이를 바꿨다. 별도 이물질 메시가 아니라 안착 불량과 힘 변화로 효과를 확인한다.

**손상 수치를 실제 차체의 파손 하중으로 볼 수 있나요?**  
현재는 부위별 가정 한계와 비교하는 등가 접촉 모델이다. 실제 항복·파단 예측으로 쓰려면 소재·두께·접합부·실측 하중을 보정하고 검증해야 한다.

**모든 장애물을 피하거나 가장 짧게 움직이나요?**  
현재 등록된 형상과 관절 제한 안에서 경로를 탐색·검사한다. 도달 불가나 간섭은 중단 조건이다. 모든 동적 상황의 회피나 수학적인 전역 최적 경로는 보장하지 않는다.

**무작위 65%가 실제 사고 확률인가요?**  
시연에서 정상과 이상을 섞기 위한 설정값이다. 실제 사고 통계에서 학습한 확률이 아니다.

**유리나 시트도 이미 장착할 수 있나요?**  
아직 아니다. 새로운 준비·실행·정지 어댑터를 등록하면 공정 진행과 스킵 UI를 재사용할 수 있는 확장 계약을 만들었다.
