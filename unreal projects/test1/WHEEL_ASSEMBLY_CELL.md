# 양쪽 로봇팔 4륜 조립 씬

## 열기와 조작

언리얼에서 `/Game/DigitalTwin/Maps/WheelAssemblyCell`을 연 다음 Play를 누른다. 별도 씬이므로 기존 `DoorAssemblyCell`은 그대로 유지된다. 화면 패널이나 `Enter`(시작), `Space`(정지), `R`(초기화)를 사용한다. 우클릭 드래그로 카메라 회전, 휠로 확대·축소, `Home`으로 시점을 복원한다. 프리셋을 누르면 해당 조건으로 초기화된다.

좌우에 배치한 네이티브 `RobotArm` 2대가 각각 앞바퀴와 뒷바퀴를 순서대로 조립한다. 양쪽 팔은 동시에 움직인다. 공정은 집기 접근 → 파지 → 들어올림 → 장착 위치로 운반 → 센서 정렬 → 가상 체결 → 해제 → 후퇴 순서다. 앞바퀴 작업 후에는 관절 공간의 보정된 뒷바퀴 준비 자세로 이동한다. 화면에는 각 바퀴의 체결 여부와 목표 장착 자세 대비 위치·방향 오차가 표시된다.

## 성공·실패 프리셋

| 프리셋 | 예상 판정 |
|---|---|
| 정상 | 네 바퀴 체결 후 `Pass` |
| 센서 오차 · 기본 | 정렬 센서에 차체 Y 방향 +5 mm 편차. 네 바퀴 체결은 끝나지만 `QualityFail` |
| 센서 오차 · 검증 | 같은 편차를 독립 자세 검사에서 발견해 체결 전 `Blocked` |
| 위치 틀어짐 | 첫 바퀴 픽업 자세가 (20, -30, 10) mm 및 yaw 2° 이동. 현재 위치에서 파지하고 정상 조립하면 `Pass` |
| 범위 초과 | 첫 바퀴가 파지 복구 범위를 벗어나 시작 전에 `Blocked` |
| 뒤집힘 | 첫 바퀴가 180° 뒤집혀 시작 전에 `Blocked` |
| 휠 없음 | 첫 바퀴를 숨기고 시작 전에 `Blocked` |

`WheelAssemblyCell` Actor의 Details에서 좌우 로봇 참조, 허브 위치, 픽업 위치, 각 팔의 휠 기준 TCP, 공차와 사용자 설정 실험값을 바꿀 수 있다. `ResetCycle`은 휠과 로봇을 초기 상태로 되돌린다. 정지 후 임의로 재시작하지 않고 초기화한다.

## 모델과 계산의 범위

현재 저장소에 타이어 메시가 없으므로 휠은 교체 가능한 검은 타이어 원통과 은색 허브 원통으로 표시한다. 차체 쪽 허브 형상, 휠 너트, 볼트 축력, 접촉 하중, 충돌 회피, 운반 장치는 아직 연결하지 않았다. 원래 차량 해석용 차체 메시에서 휠 설치 위치를 실측한 것도 아니다. 허브 중심은 차체 좌표 기준 앞/뒤 X=+125/-125 cm, 좌/우 Y=±90 cm, 높이 38 cm로 둔 **교육용 배치**다. 실제 모델을 구하면 타이어 표시 메시와 장착 기준 위치를 교체해 재보정해야 한다.

두 팔은 기존 도어 셀의 로봇 메시·관절 보정을 재사용한다. 집기와 장착 목표는 수치 IK, 5차 관절 궤적, PID 서보를 거쳐 실제 계산 TCP로 추종한다. 바퀴는 파지 시의 TCP 상대 자세를 유지해 로봇과 함께 움직인다. 체결은 도달한 자세를 고정하는 가상 상태다. `2 mm / 0.5°` 정렬값과 품질 기준은 데모 설정으로 자동차 제조 공차가 아니다. 독립 검증은 별도의 이상적인 가상 자세 측정이며 실제 카메라·센서가 아니다.

## 재생성·검증

`Scripts/setup_wheel_assembly_cell.py`는 `CamryAssemblyPreview`로부터 씬을 생성하고 두 팔의 앞·뒤 바퀴 경로를 IK 사전 점검한 후 저장한다. `Scripts/verify_wheel_assembly_cell.py`는 저장된 씬을 별도 언리얼 프로세스에서 다시 열어 정상 30/60 FPS, 기본/독립 검증 센서 편차, 위치 틀어짐, 범위 초과, 뒤집힘, 휠 누락을 검증한다. 결과는 `Saved/WheelAssemblySetup.json`과 `Saved/WheelAssemblyVerification.json`에 기록된다. 검증 스크립트는 맵을 저장하지 않으며 맵 파일 해시 불변도 확인한다.

2026-10-20 검증에서는 정상 4륜 조립이 55.92초에 끝났고 최대 장착 위치 오차는 1.82 mm, 최대 방향 오차는 0.11°였다. 동일한 정상 조건은 30 FPS와 60 FPS에서 같은 결과였다. +5 mm 센서 편차의 기본 제어는 최대 5.17 mm로 품질 불합격, 독립 검증은 체결 전 차단됐다. 위치 틀어짐은 정상 장착됐으며 범위 초과·뒤집힘·누락은 시작 전에 차단됐다. 이 수치는 언리얼 교육용 계산 결과다.
